# Power Atlas

How 197 countries compare on military, economic, technological and diplomatic power, area by area, with no single official score.

A single static page (`index.html`). Data: SIPRI, Global Firepower, FAS & SIPRI nuclear estimates, IMF World Economic Outlook, Harvard Atlas of Economic Complexity, WIPO Global Innovation Index, World Bank, Clarivate Highly Cited Researchers, GCAT (J. McDowell, planet4589.org), Brand Finance, U.S. News, Elcano, Pardee FBIC, Lowy Institute, Fragile States Index, Fund for Peace, Epoch AI (CC BY 4.0), Artificial Analysis (https://artificialanalysis.ai/), IISS, Belfer Center.
